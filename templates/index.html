Cifra de César

Um texto, uma chave e um deslocamento de caracteres.

Uma letra. Algumas posições.
Uma nova mensagem.

A lista tem $quantidade caracteres. Ao chegar ao fim, voltamos ao início. Espaços, números e pontuação ficam no lugar.

Como funciona?

A cifra de César substitui cada caractere por outro a uma distância fixa na lista. Essa distância é a chave. A ordem das letras na palavra permanece igual; o que muda é o caractere de cada posição.

abc+ 3 →def

01 / Lógica em linguagem natural

  1. Receber: ler o texto e uma chave inteira, como 3 ou −3.
  2. Preparar: normalizar os acentos e carregar a lista de caracteres.
  3. Percorrer: analisar um caractere do texto por vez.
  4. Decidir: se estiver na lista, deslocar sua posição; se não estiver, preservá-lo.
  5. Recomeçar: ao ultrapassar uma ponta da lista, continuar pela outra.
  6. Montar: juntar os caracteres na mesma ordem e exibir o resultado.
(if) e repetição (for).

02 / Pseudocódigo

Uma maneira de escrever a solução antes de escolher a linguagem de programação.

LER texto, chave e lista de caracteres
N ← quantidade de caracteres da lista
resultado ← texto vazio

PARA CADA caractere DO texto
    SE caractere ESTÁ NA lista
        valor ← posição do caractere
        novo ← ((valor − 1 + chave) módulo N) + 1
        ADICIONAR caractere da posição novo AO resultado
    SENÃO
        ADICIONAR caractere original AO resultado
    FIM SE
FIM PARA

EXIBIR resultado

03 / A matemática do deslocamento

novo valor = ((valor − 1 + chave) % N) + 1

valor − 1
A configuração começa em 1. Subtrair 1 adapta o cálculo ao intervalo de 0 a N − 1.
+ chave
Avança ou volta a quantidade de posições escolhida.
% N
Usa o resto da divisão para manter a posição dentro da lista, como uma volta em um círculo.
+ 1
Retorna à numeração original da configuração.

Exemplo: a = 1, chave 3 e N = $quantidade.

((1 − 1 + 3) % $quantidade) + 1 = 4
Posição 4 → d

N é a quantidade de caracteres configurados: $quantidade. Há $quantidade deslocamentos distintos, de 0 a $max_chave. A chave 0 mantém o texto. Chaves separadas por $quantidade produzem o mesmo resultado.

Para decifrar, use o oposto da chave: cifrar com 3 e depois com −3 recupera o texto original normalizado.

04 / Configuração em JSON

O arquivo config.json associa cada caractere a um número. Este é um trecho do início da configuração:

{
  "a": 1, "b": 2, "c": 3,
  "d": 4, "e": 5, "f": 6
}

Os valores da configuração completa devem ir de 1 até N, sem repetições ou lacunas. O Python valida essas regras ao carregar o arquivo.

Minúsculas, maiúsculas e letras acentuadas pertencem à mesma lista. Por isso, uma letra pode mudar de caixa ou ganhar acento. Espaços, números, pontuação e qualquer caractere fora da lista permanecem iguais.

JSON representa os dados da configuração; não é uma linguagem de programação.

05 / Algoritmo codificado em Python

Este é o núcleo de cifrar, em cifra.py. O dicionário valores encontra o número de uma letra; caracteres faz o caminho inverso.

caracteres = {valor: caractere
              for caractere, valor in valores.items()}
quantidade = len(valores)
resultado = []

for caractere in texto:
    if caractere in valores:
        valor_atual = valores[caractere]
        novo_valor = ((valor_atual - 1 + chave) % quantidade) + 1
        resultado.append(caracteres[novo_valor])
    else:
        resultado.append(caractere)

return "".join(resultado)

for percorre o texto, if/else escolhe o tratamento, append guarda cada resultado e join monta a mensagem final.
